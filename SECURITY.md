# Security policy

## Project status

LegalMind is a development prototype, not a production service. Do not upload confidential contracts, personal information, or credentials. The repository does not currently provide authentication, saved review storage, tenant isolation, or production abuse controls.

## Reporting a vulnerability

Please do not report security vulnerabilities in a public issue or pull request. If private vulnerability reporting is enabled for this GitHub repository, use the repository's **Security** tab to submit a private report. If that option is unavailable, contact the repository owner privately through their GitHub profile.

Include the affected version or commit, a concise description, and reproduction steps using synthetic data. Do not attach real contracts, extracted clauses, personal data, access tokens, or other secrets. Do not test against a public deployment or another person's data.

There is no guaranteed response or remediation time. Avoid public disclosure until the maintainer has had a reasonable opportunity to assess the report.

## Supported version

Only the latest code on the `main` branch is currently supported.
